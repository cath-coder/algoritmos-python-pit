# 🐍 Algoritmos e Estruturas de Dados em Python

Repositório dedicado ao armazenamento e organização dos códigos, exercícios e projetos práticos desenvolvidos durante as disciplinas do **Bacharelado em Inteligência Artificial** no **Piauí Instituto de Tecnologia (PIT)**.

---

## 📁 Estrutura do Repositório

O repositório é composto por notebooks práticos desenvolvidos no Google Colab, cobrindo os seguintes tópicos:

- **Lógica de Programação & Estruturas de Controle:** Comandos de decisão, estruturas de repetição e funções.
- **Programação Orientada a Objetos (POO):** Conceitos de classes, objetos, atributos e métodos.
- **Estruturas de Dados & Algoritmos:** Exercícios práticos e resoluções de problemas da graduação.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Python 3
- **Ambiente de Desenvolvimento:** Google Colab / Jupyter Notebooks
- **Controle de Versão:** Git & GitHub

---
